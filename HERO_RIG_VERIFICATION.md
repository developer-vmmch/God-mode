# HERO RIG & CHARACTER MODEL REPORT — CSVS GOD MODE V0.3

## 1. Hero Model Overview (`Hero_Armored.fbx`)

- **Design Philosophy**: Original athletic superhero character inspired by coastal Indian resilience and modern sci-fi exosuit engineering.
- **Scale**: $1.88\text{ m}$ height, anatomical proportions calibrated for high-speed dynamic flight and ground combat.
- **Mesh Topology**: Single unified mesh topology with clean UV Smart Projection islands, ready for skinning and animation blend trees.
